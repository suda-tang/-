# 全项目回归检查 — 2026-10-29

## 本轮结论

213 项 Python 测试、37 项 Node 测试全部通过。187 个前端脚本语法检查通过；295 处本地模块引用没有缺失文件。另通过 17 组 AI、课堂和数字人专项检查。此结果不是所有设备、外部服务和界面的无故障保证。

## 修复内容

1. 鼓伴奏：原先每小节重复加入开镲、弱军鼓，并且开镲与闭镲同拍叠加。改为在选定乐句位置添加，开镲替换同拍闭镲，保留基本节拍和四/八小节加花。新测试检查不会同拍叠打，已有测试验证与钢琴起音数量无关。
2. 曲名回退：不再无条件截取连字符前半段而把歌手当作曲名。优先以目录确认曲名；无法确认的双段文件名保留完整内容。英文标题内部连字符不再丢失。封面图片本身不足以确认曲名，缺少 matchedTitle 时不会抛错或视作已核验。
3. AI 搜索：检查返回对象及 matches 类型；HTTP 异常没有 response 对象时也能返回明确错误，不再引发二次异常。
4. 音源模块：DOM 监听改为环境检查，允许播放核心在无 DOM 的测试/模块环境初始化。
