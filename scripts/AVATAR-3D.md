# Full-body 3D narration viewer

The current implementation is a real skinned GLB, with geometry on all sides, orbit rotation, pinch/wheel zoom, full-screen viewing and jaw/blink motion. It replaces the previous flat talking-head video UI. The face is now an approximate fit from the authorized mentor footage using MediaPipe 0.10.21 (CPU): 468 facial landmarks, regularized vertex deformation and surface-bound skin coordinates. This is not a scan or photorealistic identity reconstruction. Hair, rear head and body remain generic.

Asset: mentor-base.glb, downloaded from https://github.com/met4citizen/TalkingHead/blob/main/avatars/mpfb.glb on 2026-10-03. The repository README identifies this MPFB example as CC0: https://github.com/met4citizen/TalkingHead#credits . Software rendering uses Three.js 0.180.0 (MIT); the license is kept under dist/vendor/three/LICENSE. The model contains an embedded full-body mesh, suit, hair, Mixamo-compatible bones and facial morph targets. It is not the screenshot pictured in the repo's older MPFB documentation.

All runtime assets are self-hosted. The original GLB is 36,815,920 bytes; mentor-runtime.glb is 12,980,480 bytes after retaining required morph targets and compacting embedded textures. Rig, vertex topology and UVs are preserved. HTTP/browser caching plus an in-memory byte buffer avoid repeat downloads during a session. The upload reference footage remains private; only a cropped authorized face texture and fit data are published. No camera-facing portrait plane is used.

Face build chain: calibrate-avatar-face.cjs -> extract-mentor-face.py -> export-avatar-face.cjs -> fit-mentor-face.py. The extraction script matches the reviewed close-up shot against uploaded-frame12.png and rejects B-roll with other people. 17 matching frames were evaluated, with 12 stored estimates; frame at 9 seconds supplies the current skin texture. MediaPipe's weak-perspective depth is approximate, so a regularized shared deformation field is used for skin and eyes. compact-mentor-model.py generates the runtime GLB. The face env uses Python 3.10, MediaPipe 0.10.21, numpy 1.26.4, SciPy 1.15.3 and OpenCV 4.11; optional JAX packages are removed to reduce CPU memory use. An ASCII junction under C:/Users/mail/.cache/suda-face-env avoids MediaPipe's Windows Unicode path issue.

Texture fixes: standard UVs require flipY=true for the PNG; glTF texture settings must not be copied to this standalone texture. Decode reference sRGB explicitly after scene tone mapping to avoid applying studio lighting twice. Extend UVs at zero-weight boundary vertices to avoid triangle streaks; retain a smooth mask at the face outline. Face texture URLs contain a content revision; fit JSON is fetched without stale HTTP caching. preview-mentor-face.cjs renders real WebGL front/side close-ups for inspection.

Narration retains the existing audio element. Jaw movement is driven by audio amplitude, not Chinese phoneme alignment. Bones retain their resting pose with small head/torso movements. WebGL resources, audio analysis and event listeners are released when the guide exits. Full-screen view is portalled to document.body to avoid transformed parents clipping the viewer.

Validation: node scripts/check-avatar-3d.cjs ; node scripts/check-narration-opening.cjs . Inspect front, rotated and back screenshots under .sites-runtime/avatar-source. Test desktop and mobile gestures, expand/close and continue-to-guide cleanup.
