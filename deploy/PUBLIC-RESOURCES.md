# 公开资源与隐私边界

代码进入 Git；大型公开运行组件进入本仓库 GitHub Releases。恢复工具读取已经提交的 SHA-256 清单，不会上传用户文件。

公开资源包括 Audiveris 运行目录、PianistTransformer、Structured-Arrangement、GrooveTransformer、SadTalker、3DDFA、ZipVoice、CosyVoice 原版源码与模型、音轨分离模型、已有翻译模型、转录依赖、Three.js 运行资源、通用男声导览和项目背景音乐。第三方原有许可证随相应组件保留。

以下内容保持本机私有：

- 学校账号、密码、Cookie、WebVPN 认证会话、浏览器配置、访问密钥。
- 用户上传的曲谱、音视频、人声绑定、处理任务、练习记录及其缓存。
- 导师和唐秋鸣的原始录音、录像、照片、训练数据、个人音色微调权重、身份特征与个人三维头像资产。
- 访客姓名关联的专属问候语音。
- 博士申请信、导师候选名单、研究材料及包含个人申请信息的链接生成页面。

虚拟环境、node_modules、日志、字节码、下载残片、重复压缩包、第三方 Git 历史不重复上传。依赖通过版本锁与安装命令恢复；没有把这些内容算作可直接迁移的运行环境。

发布打包器采用目录白名单，不遍历账号、作品库和训练素材目录。源码里的模型路径已支持项目内恢复目录，保留旧部署兼容路径。
