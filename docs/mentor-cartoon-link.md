# 导师导览卡通形象参数

2026年10月22日起，中文导览暂时默认使用卡通形象：`lang=zh`、`zh-CN`、`zh-Hant`、`yue`及未指定语言的默认中文导览均适用，不必增加参数。英文等其他语言保持原行为，仍可用`avatar=cartoon`明确选择卡通版。中文导览中的显式`avatar=portrait`也暂时服从中文默认规则。此规则同时覆盖首次预加载、画面姓名、正文音频及专属问候，不影响普通主页。

在原有导览链接末尾增加 `&avatar=cartoon` 即启用定制卡通形象。不带此参数时，原版形象、姓名和讲解保持不变。

示例：`https://suzhou.super-tang.com/?tour=1&auto=1&avatar=cartoon`。已有的 `mentor`、`institution`、`direction`、`lang` 等参数保留，来访教师的称呼、院校和校徽不受影响。

卡通版为独立程序化三维模型，保留长发、蓝色上衣、深色裙装及项链等造型，使用立体卡通五官、眨眼和开口动作，复用现有讲解、步行及指示动画接口。不读取真人面部照片或照片重建的面部网格，预加载入口也跳过这些资源。

画面中的讲解者姓名替换为“音乐教师”或相应英文身份；来访者姓名仍正常显示。根据2026年10月21日的新要求，卡通链接的前言删除“我是苏大音乐学院的冒小瑛”一句，在原录音3.82至6.20秒的停顿处剪接，其余正文保留原声。专属姓名问候和静态前言均采用该版本，无参数链接保持原版音频。

模型采用参考照片测得的五官间距、脸型比例和侧分长发特征，使用连续光滑的卡通头部网格，不使用照片贴脸。嘴部随新音频包络运动。当前版本是参考特征调整，不能据此声称已实现真人高度还原。

`scripts/check-cartoon-audio121.cjs`检查新音频完整解码、两种模式的专属问候拼接、其他六段讲解保持一致，以及外网与本机文件一致性。

`scripts/check-cartoon-mentor.cjs` 在390×844移动视口中实际打开卡通导览，检查多个语音播放位置下的字幕、板书绘制文本、模型材质和网络请求。结果：原姓名显示数0，真人面部资源请求数0，模型照片贴图数0，无页面错误；另检验无参数时身份文本保持原版。截图：`.sites-runtime/avatar-source/cartoon-mentor120-mobile.png`。
