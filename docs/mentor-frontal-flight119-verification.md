# 拙政园正面跟拍及离地转场

日期：2026-10-21。发布版本：`mentor-garden-walk119-20261021`。

## 原因和修订

拙政园原联合路线的全部相机点均在人物行进方向后方。现在反向编排同一条经过检验的步道，同时反向镜头路线、翻转曲线切向量并重算共同时间表；入口站点和预加载焦点同步更换。无需让导师倒着走，也无需在运行中绕到人物前面。构建器加入朝向整理步骤，之后重建不会恢复成背面跟拍。

树木遮挡采用局部视线保护：只有相机与导师之间、覆盖人物的那一小部分枝叶或树干逐步淡化，其他实例和背景树木保留。使用共享GPU参数和静态像素抖动，不逐帧遍历整座园林做射线搜索，也不修改透明绘制排序。材质处理在围墙裁切以后应用，避免被后续材质克隆覆盖。

原避障档案记录了模型表面，缺少园林地基抬高后的最低飞行高度，规划可能从薄地面下面绕过障碍。新增由实际园林轮廓生成的地面高度带，镜头的扫掠检查和路径搜索均须满足地面高度加安全间隙。地面约束独立于人物视线判断，不把人物脚下的铺装当作观看障碍。

转场视线不再追逐航线切线，使用起止方向之间的单向平缓衔接，限制峰值角速度约0.24弧度每秒。虎丘、北寺塔的讲解位置和朝向配合来向安排，将接近半圈的观看方向调整分散到相邻场景。仍保持镜头路径、讲解位置和最终板书方向一致，不以落地跳镜解决朝向差异。
