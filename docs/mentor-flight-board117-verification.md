# 导览运镜及报告板书修订

2026-10-21，发布版本 `mentor-garden-walk117-20261021`。

镜头俯角不再跟随航线的爬升、下降切线，而是连续衔接起止观看俯角。移除强制后退、垂直爬升、重复进场节点，普通地标间直接规划安全通道；钟楼出发仅保留必要的安全转角。规划检查必须同时吻合起点和终点，不能通过悄悄移动镜头起点来取得可行路线。园林进场沿用园内镜头体积，避免落地时切回另一位置。

黑板离场保存当前位置、旋转和画布纹理快照，旧板书完整升起后释放快照。目的地的真实黑板只在降落阶段显示，飞行途中隐藏。快照只销毁自身新增的纹理及材质，不销毁原板书共享资源。

七段板书分别设计：课题起点、音乐材料的统一表征、课堂指令的执行过程、课堂活动的组织、教学材料的修订、反馈时机的教学效应、项目演示。照片在开场期间预先读取，其他图示为轻量矢量绘制，包含谱面、键盘、声部、波形、课堂人物及反馈时间线；随讲解分步呈现，并保留持续的播放指示动画。左侧身份区预留不变，标题不含斜杠，不显示页码。示意时间线不作为实验结果展示。

外圈围墙通过独立边界遮罩裁切，包括墙面、柱和压顶；底板遮罩单独保留，植被透明材质不使用围墙裁切。建筑内部不按整块材质删除。检查包含真实拙政园模型渲染和两座园林的实体围墙、透明植被材质像素对照。

验证脚本：

- `check-mentor-flight-gaze.cjs`：高度明显起伏的航线上，视线俯角保持在两个端点之间，最大相邻采样变化约0.000093弧度。
- `check-mentor-worker-flight.cjs`：六段航线均无避障命中，航程分别约130.93、27.81、97.21、42.22、61.54、44.51米。
- `check-garden-real-transition.cjs`：实际怡园终点至拙政园入口通过连续碰撞及两端位置一致性检查。
- `check-mentor-report-and-board-lift.cjs`：七段画面都有动画变化，照片已绘制；无标题斜杠和页码；旧板书纹理冻结，升起后资源释放，不影响原板书。
- `check-garden-perimeter-materials.cjs`：两园的外圈实体墙被裁切，透明植被测试对象保留。
- `check-mentor-route-visuals.cjs`：额外逐帧检查飞行期间真实黑板和旧板书快照均不出现在画面中。
- `check-mentor-route-release.cjs`及`check-mentor-presentation-release.cjs`：模块语法及外网静态文件核对。
