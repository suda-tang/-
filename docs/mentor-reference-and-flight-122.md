# 卡通参考塑形和转场检查

2026年10月21日更新。

卡通模型采用已授权参考的面部关键点，拟合脸部轮廓、眼距、嘴角位置及面部深度。连续头部网格代替独立鼻子和椭球拼接，眼睑、牙齿、嘴唇、侧分发际线和卷发另行建模。所有材质保持卡通，不将本人照片贴在脸部。参考塑形改善不等同于已经实现真人级相似度，不能仅凭自动检查宣称高度还原。

飞行路径新增起降通道选择。讲解点可能位于窄园路，镜头先沿局部安全路径离开，主要旅行段采用1.9单位的宽镜头避障体积；窄路无法通过时保留原有安全规划回退。时长按实际路径长度和朝向差计算，限制在5.5至12秒，保留首尾速度缓变。此次没有挪动整座园林：模型、地面高度、步行路径、树冠碰撞及飞行体素相互绑定，不能只平移可见模型而留下错误的碰撞位置。

验证：`check-mentor-worker-flight.cjs`六段真实障碍路径每段采样601点，无碰撞；`check-mentor-full-route-edge.cjs`在390×844浏览器中依次到达钟楼、怡园、拙政园、虎丘塔、北寺塔、山塘街、返回钟楼，无场景加载/路径错误，无黑板闪现；`check-cartoon-mentor.cjs`检查无本人姓名显示、无照片贴图、无真人面部资源请求；`check-mentor122.cjs`检查时长上下限、轨迹连续性、模型数值以及外网文件一致性。
