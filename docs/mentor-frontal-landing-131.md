# 转场入镜朝向和避障复核

导师在转场末尾已经显示，但旧逻辑仍采用地标默认朝向；直到园林步行更新时才转向镜头。黑板亦存在相同的朝向交接。因此只保证落地后的姿态正确仍会出现“先背对、再突然纠正”。

本轮增加统一的入镜朝向处理，在实际渲染前根据最终镜头位置确定正面。转场时导师直接采用朝向观众的姿态，黑板亦朝向观众；讲解步行保留有限侧转并使用最短角度缓动，不把旧地标朝向带入新镜头。上岸动作继续使用原动作朝向，不将横向上岸误当成讲解站位。

飞行中的拖动原来围绕注视目标移动相机，可能让相机离开已经验证过的安全路径。现在飞行中拖动改变观看方向，相机物理位置仍沿规划路线。巡航入口允许从窄园路局部退出，主要巡航保持较宽避障空间；最终平滑路线也按巡航空间验证，避免圆角把宽通道又削窄。Worker返回结果后，主线程用刚刚加载完成的障碍信息再次核对路径，过期路径会重新规划。

`check-mentor-worker-flight.cjs`验证六段路径；`check-mentor-facing131.cjs`在移动视口记录新地标入镜时导师及黑板的正面向量，并在飞行中执行拖动来比较实际镜头和规划轨迹。以上检查针对已纳入场景避障的数据，不能据此宣称任意未知模型均已永久杜绝穿模。
