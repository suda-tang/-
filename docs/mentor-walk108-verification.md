# 导览步行与转场修订（2026-10-21）

## 本次改动

- 校门至校园采用连续推进，取消原来整段缓入造成的门前低速停留。
- 钟楼出发先经过前院的开阔侧面，再进入西侧通道。转场不再贴着钟楼屋顶或后墙切过去；中间航段保留较宽的避障间隙，关闭侧倾。
- 园内镜头采用步行高度的持续跟拍，取消按时间摆动与固定周期绕拍。区分镜头的体积避障和人物视线的射线检查，避免把镜头半径应用到人物脚下后错误判断地面遮挡。使用离线源三角面体素数据及有限次数的源网格确认。
- 怡园、拙政园以建筑围合轮廓裁切低矮外底板，不删除原有墙体、桥梁和台阶。裁切材质支持实例化模型和校园坐标平移。
- 园内行走使用离线源几何采样，排除低于正常铺装的池水面，保留合法高度变化，减少反复折返。路线每个相邻采样间隔不超过 0.25 米。
- 地标标牌仅在镜头靠近、文字可见、支脚及牌面未与模型相交时落位书写，不能找到位置时继续等待；不强行插进假山、树干或讲台。
- 转场保留出发位置的导师姿态，待其离开相机视锥后再移除。姿态共享几何和材质，移除时不销毁仍在使用的人物资源。
- 跨场景落地时清除上一场景高度的平滑继承，避免从抬高的园林地面到虎丘时仍悬在空中。

## 重建

运行 `scripts/build-garden-walk-surface.py` 从源模型重建建筑轮廓与步行网格，随后自动运行 `scripts/refine-garden-walks.py` 剔除低位池水路径并整理参观顺序。此过程是离线构建，浏览器不承担源模型扫描。

`scripts/cache-garden-floor-heights.py` 可单独生成全域高度缓存，供路线细化使用。更换源模型后应重建此缓存。
