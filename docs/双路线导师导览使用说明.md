# 导师导览：音乐教育与 AI 技术

在 `/research.html` 选择路线，填写来访导师姓名、院校和语言，点击生成分享链接。链接中的 `direction` 明确选择路线，不会被旧的导师档案覆盖。

## 音乐教育

`/?tour=1&auto=1&direction=education&lang=zh`

先从选曲、聆听比较、连续追问进入课堂，再解释课件、课堂动作、学生参与、跟弹反馈和研究设计。围绕一个问题组织介绍：学生的音乐判断怎样变成可以核对的声音证据，反馈又怎样影响下一次学习行为。

## AI 技术与计算机

`/?tour=1&auto=1&direction=technology&lang=zh`

先追踪多种材料进入系统后的表示、时间基准和声部身份，再解释指令解析、工具执行、条件校验、课堂状态、任务恢复与研究验证。介绍重点是跨模块的一致性，而不是罗列模型名称。

两条路线均含 44 个环节，支持目录跳转。部分环节会操作实际工作区：曲库分类、视图切换、声部试听、小节范围、音乐分析和课堂配置。操作结果来自当前作品；失败时保留原因，不用预写成功结果替代真实执行。

导师数字人仍在前面介绍项目；后续由唐秋鸣的导览说明实现与判断。本次没有调整导师正文预合成、姓名问候轻量合成的既有方案。

## 分享前核对

1. 填写导师姓名、院校，选定路线和语言。
2. 用生成的链接打开，确认来访信息与导览目录。
3. 选一首已经就绪、声部信息完整的作品用于演示。
4. 用课堂配置演示检查全曲范围、学段和课时；生成课件由使用者继续确认。

跨作品动机检索、任意录音的乐器分离、作曲意图解释等，不能仅凭模型回答宣称验证完成。导览将已有功能、结果核对与待研究问题分别说明。
