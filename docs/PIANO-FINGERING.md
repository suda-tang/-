# 钢琴自动指法

入口：演奏 → 跟弹练习 → **标注钢琴指法**。先选择钢琴乐器。
支持已经识别完成的 PDF、MusicXML、MIDI；未识别的图片/PDF 须先完成识谱。

数字为 1 至 5，分别对应拇指到小指。双谱表默认按谱表分左右手；
单谱表暂按中央 C 分手，可以在指法设置中指定全为左手或右手。
跨谱表记谱或复杂分手需要教师核对。可选偏小、适中、偏大三种手型。
生成时显示实际已处理音符的百分比，同时进入任务中心。
点电子谱上的指法数字可改成 1 至 5；开关只控制数字，不停止播放。
导出指法按钮输出标准 MusicXML `notations/technical/fingering`。

## 实现

- 开源引擎：[PianoPlayer](https://github.com/marcomusy/pianoplayer) 3.0.2，MIT。
  未修改的必要源码和许可证放在 `vendor/pianoplayer`，无需显卡、账号或额外 pip 包。
- `scripts/piano-fingering.py` 适配器使用原优化器的键盘几何、指间跨度和转指代价。
  逐起音滚动搜索至多七个音符，并整体保留同一和弦的指法。
  修复的是调用层对短尾窗的处理，避免低搜索深度复用未求解的零值。
  原谱和手动指法作为固定约束，重复琴键合并，不强制给超过五键的单手和弦填数字。
- `fingering_service.py` 单工作进程队列，计算与 HTTP 隔离，最长五分钟。
  进度是实际音符计算进度。不会把浏览器操作当成暂停计算的条件。
- `.sites-runtime/fingering-cache` 保存按音符内容、分手、手型和引擎版本散列的结果，
  以及手动修订。再次标注同一版本直接复用结果；重新打开会自动取服务端已保存的指法。
  本机另存一份，服务不可用时仍可查看本机缓存。
- 只对电子谱 SVG 添加交互数字，不重建播放器、不修改播放音符或时间轴。
  切换视图/延迟渲染新小节时重新挂载标注。

这是按音乐内容和手部几何求得的练习建议，并非逐曲人工审定的教材指法。
它不从 PDF 图像上猜数字；PDF 的识谱准确性仍须先核对。

## 验证

```
python -m unittest discover -s tests -p test_fingering.py -v
node scripts/check-practice-fingering.cjs
```

覆盖双手音阶、和弦、原谱固定指法、短曲末尾、重复键、不可行和弦、服务端修订保存，
以及 390 / 1440 像素浏览器真实生成、标注、编辑、隐藏和 MusicXML 往返时值不变。
