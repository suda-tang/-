# 导师播放、分身及背景音乐修复

2026年10月21日。

问题根因：恢复页面可见状态及点击解锁会直接调用语音播放，没有检查当前场景是否转场完成；语音的结束事件因此可能在原场景继续推进后续章节。离场导师采用共享几何的静态副本，在回到视野时，旧副本可能仍在视锥内，与新导师同时显示。

修复后的约束：只有当前段场景就绪才能播放、响应自然结束并进入下一段；转场时禁用跳段，恢复页面及点击不绕过场景等待。路径失败时自动重试一次，继续失败则留在当前段显示原因和重试入口，不默默播放后续段落。园林地面下载等待超过20秒会进入这套恢复流程。每次转场先移除旧副本；新导师显示时移除离场副本；同一导览容器的重复初始化复用同一个播放流程。

评弹和导师声音可以重叠。以媒体实际`playing`、`pause`、`waiting`和结束事件判断是否说话；说话时评弹降至原音量30%，暂停后平滑恢复。当前评弹原音量18%，压低后为5.4%，不改老师音量。结束导览仍释放音乐及事件监听。

卡通头部：缩短过长下颌、柔化脸部轮廓和眼线，修复眼白和牙齿曲面背面剔除，继续保留参考塑形。未据此宣称达到真人高度还原。

验证：`check-mentor-stall123.cjs`在390×844触摸视口故意延迟飞行规划，连续模拟页面恢复、点击及结束事件，确认只停留当前段、语音暂停、无两名导师同时可见，到场后自动续播；`check-mentor-recovery123.cjs`额外注入一次路径异常；`check-mentor-duck123.cjs`实际播放音频检查18%→5.4%→18%；七段完整浏览器检查无路径错误或黑板闪现。
