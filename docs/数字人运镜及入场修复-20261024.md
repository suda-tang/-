# 数字人运镜及入场修复

版本：mentor-camera132-20261024。

## 行为

- 仅简体中文导览使用卡通人物；繁体中文、粤语及其他语言使用肖像数字人。首页早期预加载、音频选择和三维模块共用同一判定规则。
- 移除等待语音时绕飞古城的分支，直接走校园路线。网页解析时即请求姓名问候、预载正文及后续两段音频，首次请求增加超时，避免悬挂请求阻断轮询。
- 固定正文仍采用预合成音频，姓名问候仍采用原轻量模型。专属问候超过开场准备预算时先使用原有正文，不重新合成长篇，也不无限等待；此时不会把迟到问候插进正在播放的句子。
- 飞行巡航镜头扩大避障间距，中段规划不再悄悄降级为步行级窄间距。近距离跟拍扩大构图视野；手动轨道避障不会把被墙挡住的后退操作反变成贴脸前进。
- 山塘街上岸前收起黑板，上岸中保持隐藏，落地机位稳定后再展示。离场副本采用独立材质渐隐，避免影响实体材质。
- 黑板升起完成后移出显示；返回时保留原有板书位置和朝向，避免瞬间复位。钟楼内部页面投影仅在进入教室后显示，拒绝近平面和相机背后的角点，避免异常透视矩阵闪屏。
