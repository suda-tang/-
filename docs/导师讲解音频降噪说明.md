# 导师讲解音频处理

保留原始 VoxCPM 录音，未更换声音合成引擎。原文件以 .voxcpm.m4a 结尾，处理版本以 .voxcpm.clean.m4a 结尾。七段全部解码校验成功后，原子更新 tour.json。

处理脚本：scripts/clean-mentor-audio.py。采用 60 Hz 高通、FFmpeg arnndn（mix=0.9），回采样至 24 kHz，AAC 128 kbps。

模型为 Xiph RNNoise 标准模型 std.rnnn，来源 https://github.com/richardpl/arnndn-models ，模型摘要及参数记录在 .sites-runtime/voice-denoise/processing.json。原清单备份在同目录 tour-before-clean.json。

FFmpeg 文档：https://ffmpeg.org/ffmpeg-filters.html#arnndn 。RNNoise 项目和授权：https://github.com/xiph/rnnoise 。

降噪只能改善噪声，不构成人声保真度或语音自然度的主观评测结论。
